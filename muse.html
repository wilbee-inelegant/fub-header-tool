How the conversion and Muse setup work

Follow Up Boss uses HTTP Basic authentication: the API key is the username and the password is empty. The tool encodes UTF-8 bytes of API_KEY: (including the final colon), then adds Basic . The header name is Authorization.

  1. Have Muse establish its supported direct REST connector and protected credential flow, restricted to api.followupboss.com.
  2. Generate the value here or in your disconnected local copy. Copy it only into that approved credential form.
  3. Ask Muse to perform one minimal, authorized read-only identity check. This tool does not contact FUB or validate your key.

This direct REST route was reported working in one owner’s Muse account. It is not an MCP installation, and its permissions must be checked separately. A read-only test does not make the API key read-only. Account features and labels may differ.

Using ChatGPT’s FUB MCP adapter instead? Enter the raw API key in its protected FUB_API_KEY setting. Do not put this generated header there.
