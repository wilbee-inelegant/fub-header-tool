FUB Header Generator

Paste a Follow Up Boss API key. This page runs entirely in your browser — nothing is sent anywhere, there's no server involved, and closing the tab discards everything.

FUB auth is plain HTTP Basic Auth: the API key as the username, an empty password. No X-System / X-System-Key headers are included — those only matter if you've registered as a named FUB integration (needed for webhook signature verification), not for a plain authed request.
